React Todo App

Aplikasi Todo sederhana yang dibuat untuk React take-home test. Fitur yang tersedia meliputi menambah, menampilkan, menandai selesai, menghapus, dan memfilter todo menggunakan React functional components dan hooks.

Cara Menjalankan

Pastikan Node.js versi 18+ sudah terpasang.

Instal dependensi: npm install

Jalankan server pengembangan: npm run dev (atau npm start)

Buka URL yang muncul di terminal (biasanya http://localhost:5173
)

Fitur

Menambahkan todo (melalui input, tombol Add, atau tekan Enter)

Menampilkan daftar todo dengan key yang unik

Menandai todo sebagai selesai atau belum selesai

Menghapus todo

Filter: Semua / Aktif / Selesai

Menghapus semua todo yang sudah selesai

Desain responsif (menggunakan CSS dan beberapa inline style)

Catatan

Dibangun menggunakan React functional components dan hook useState.

Styling menggunakan class CSS (src/App.css) serta beberapa inline style di TodoItem.
